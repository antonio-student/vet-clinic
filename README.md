# Platformă pentru Clinica Veterinară

## Descrierea proiectului
Aplicație web pentru gestionarea unei clinici veterinare, permițând evidența medicilor, pacienților (animale), stăpânilor și a programărilor.

## Arhitectură
Aplicație  dezvoltată în Java / Spring Boot. Folosește Spring Data JPA pentru persistență, Spring Security pentru autentificare și Thymeleaf pentru frontend.
